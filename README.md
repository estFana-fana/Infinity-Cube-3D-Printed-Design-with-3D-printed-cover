# Infinity-Cube-3D-Printed-Design-with-3D-printed-cover
This is a simple CAD design project inside Fusion 360 of an infinity cube with a caste for it.
This project is based on a tutorial on Youtube created a channel called Michael D'Argenio [Link to the tutorial](https://www.youtube.com/watch?v=UlSd0zvG-_E)
